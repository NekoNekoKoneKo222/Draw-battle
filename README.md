# DRAWMON — Draw Battle

ブラウザで絵を描き、名前とイラストの照合AIと絵の特徴分析でオリジナルモンスターカードを作り、コレクション・CPU対戦・オンライン対戦を楽しむWebゲームです。

## ゲーム機能

- **お絵描き** — 名前を先に決め、12色のキャンバスで絵を描く。
- **カード生成** — Transformers.js の CLIP（`Xenova/clip-vit-base-patch32`、ブラウザ内実行）でイラストを文章の候補と比較。カード名から検出した属性・生き物のキーワードと絵の一致度に加え、色・線・対称性を使って属性、レア度、HP、ATK、DEFを評価。3つの技も自動生成。普通の猫などに特殊な属性を無理やり付けない「ノーマル」タイプに対応。
- **コレクション** — ブラウザ内の自動保存、クラウドへの手動セーブ／ロード、カードの並び替え。
- **公開ギャラリー** — 自分のカードを公開／非公開に切り替え、ほかのユーザーの公開カードを閲覧。
- **バトル** — CPU対戦と、6文字の部屋コードを使った2人オンラインターン制対戦。

## 技術構成

- フロントエンド: `public/game.html`, `public/style.css`, `public/app.js`（Canvas、ブラウザlocalStorage）
- サーバー: Vinext / Cloudflare Workers、`app/api/game/route.ts`
- DB: Cloudflare D1（`drawmon_cards`, `drawmon_rooms`）
- 画像: Cloudflare R2
- 認証: ホストが提供するChatGPTサインイン。書き込み操作、個人データへのアクセス、部屋の手番はサーバー側で認可。
- AI: Hugging Faceのモデルをブラウザ側で実行するため、画像推論のAPI利用回数に比例した料金は発生しません（初回に約150MBのモデルデータを取得し、端末の性能とメモリが必要）。モデルが使えないときは名前キーワードと色・形による簡易評価に切り替わります。

## 開発

Node.js 22.13以上が必要です。

```bash
npm ci
npm run db:generate
npm run dev
```

`.openai/hosting.json` でD1とR2バインディングを宣言し、ホスティング側で実際のリソースを割り当てます。ローカルD1の初期化やビルド、デプロイの詳細はSitesのVinextスターターの手順を参照してください。

## 注意

- ローカルセーブとクラウドセーブは別です。別端末では「ロード」を使って取得できます。
- クラウドカードはアカウント単位で管理されます。カードの公開操作をすると絵、名前、能力がギャラリーに表示されます。
- 公開ギャラリーとオンライン対戦を複数の人で使うには、ホスティングの閲覧者権限が必要です。Webサイトが本人限定の場合、招待された人以外は参加できません。
- CLIPの判定は文章候補との相対的な比較であり、イラストの正確な理解や客観的な芸術点を保証するものではありません。名前の意味は日本語・英語の主な属性／生き物キーワードで抽出し、辞書にない独自名については一致度を付けずイラストを中心に評価します。
- 通常の動物名（例：「ネコ」）で特殊な属性名がないカードはノーマルタイプになります。「炎ネコ」など名前に属性があればその属性を優先します。属性名がない独自名では絵の色とCLIPの属性判定が一致した場合のみ特殊属性を付けます。
- 旧バージョンのブラウザカードは、起動時に保存IDの形式が補正されます。
- このゲームはオリジナル作品です。既存のポケットモンスターの画像、名前、音楽、ゲームデータは使用していません。
